Part-1: What are CI/CD?
CI- CONTINUOUS INTEGRATION -Automatically validates the code changes through tests and build checks
CD- CONTINUOUS DELIVERY-keep changes ready to release, with production release potentially requiring approval
CD- CONTINUOUS DEPLOYMENT- Auromatically release changes go production when all required checks pass
